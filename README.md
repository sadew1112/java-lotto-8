# 로또

## 구현할 기능 목록
### 입력 기능
1. 사용자로부터 로또 구입 총 금액을 입력받는다.
2. 사용자로부터 당첨 번호를 입력받는다.(번호는 쉼표로 구분해서 숫자 리스트 형태로 변환 후 반환)
3. 사용자로부터 보너스 번호를 입력받는다.(1개만 가능)

### 검증 기능
1. 로또 구입 금액은 1000원 단위인지 체크
2. 당첨 번호에 숫자 이외의 문자가 포함되어 있지 않은 지 체크
3. 보너스 번호가 일반 당첨 번호와 중복되거나 1개 이외 개수의 값이 들어오는 지 체크

### 로또 번호 발행 기능
1. 입력받은 구입 총 금액을 1,000으로 나누어 로또 개수를 계산한다.
2. 계산된 수만큼 로또 번호를 자동으로 발행한다.
3. 한 장의 로또 번호는 숫자 1 ~ 45 사이의 중복되지 않은 6개 숫자로 구성한다.

### 당첨 확인 기능
1. 앞서 발행된 개별의 로또와 당첨 번호 간의 일치 개수와 보너스 번호 일치 여부를 확인한다.
2. 등수 기준에 따라 등수를 판정한다.
3. 모든 로또 번호에 대한 결과를 등수 별로 리스트에 저장한다.

### 수익률 계산 기능
1. 받은 당첨 결과 리스트를 바탕으로 수익률을 계산한다.
   1-1. 수익률 : (총 당첨금 / 구입 금액) × 100
   1-2. 소수점 둘째 자리에서 반올림

### 출력 기능
1. 구매한 로또 개수 안내 멘트와 함께 발행된 모든 로또 번호를 출력 형식에 맞게 출력한다.
2. 등수별 당첨 통계를 출력 형식에 맞게 출력한다.
3. 총 수익률을 출력 형식에 맞게 출력한다.

## 예외 상황
1. 로또 구입 금액을 입력 받을 때 구입 금액은 1,000원 단위로 입력 받으며 1,000원으로 나누어 떨어지지 않는 경우 예외 처리
2. 구입 금액이 숫자가 아닌 경우 예외 처리
3. 당첨 번호는 쉼표(,)를 기준으로 구분
   3-1. ,와 1~45 사이의 숫자가 아닌 다른 문자가 들어오는 경우 예외 처리
4. 당첨 번호의 갯수가 형식에 맞지 않으면 예외 처리
   4-1. 일반 번호 갯수가 6개가 아니면 예외 처리
   4-2. 보너스 번호 갯수가 1개가 아니면 예외 처리
5. 당첨 번호 내의 중복된 숫자가 있는 경우 예외 처리
   5-1. 먼저 입력 받은 6개의 번호 내에 중복 숫자가 있으면 예외 처리
   5-2. 보너스 번호가 먼저 입력 받은 6개의 번호 내에 존재하면 예외 처리
6. 로또 번호 6개의 숫자 중에 중복된 숫자가 있는 경우 예외 처리
7. 로또 번호 개수가 6개가 아닌 경우 예외 처리
8. 로또 번호가 1~45 사이의 숫자가 아닌 다른 문자 or 숫자인 경우 예외 처리

## 기능 요구 사항
1. 로또 번호의 숫자 범위는 1~45까지이다.
2. 1개의 로또를 발행할 때 중복되지 않는 6개의 숫자를 뽑는다.
3. 당첨 번호 추첨 시 중복되지 않는 숫자 6개와 보너스 번호 1개를 뽑는다.
4. 당첨은 1등부터 5등까지 있다. 당첨 기준과 금액은 아래와 같다.
   4-1. 1등: 6개 번호 일치 / 2,000,000,000원
   4-2. 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
   4-3. 3등: 5개 번호 일치 / 1,500,000원
   4-4. 4등: 4개 번호 일치 / 50,000원
   4-5. 5등: 3개 번호 일치 / 5,000원
5. 로또 구입 금액을 입력하면 구입 금액에 해당하는 만큼 로또를 발행해야 한다.
6. 로또 1장의 가격은 1,000원이다.
7. 당첨 번호와 보너스 번호를 입력받는다.
8. 수익률은 소수점 둘째 자리에서 반올림
9. 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 출력하고 로또 게임을 종료한다.
10. 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시킨다.
11. 이때 [ERROR]로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.
12. Exception이 아닌 IllegalArgumentException, IllegalStateException 등과 같은 명확한 유형을 처리한다.
